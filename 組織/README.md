# 組織

このディレクトリは、本プロジェクトの作業を分担する「組織」の定義を置く場所。

実行ルールの本体は リポジトリ直下の [`CLAUDE.md`](../CLAUDE.md) にある。
本ファイルは**組織一覧と運用手順の正本**であり、組織を追加・変更したらここを更新する。

| ID | 組織 | 役割 | 主な成果物 | 定義 |
|----|------|------|-----------|------|
| 01 | 企画 | 依頼内容を要件・受け入れ基準へ分解し、分担案を作る | 要件メモ、受け入れ基準、分担案 | [組織定義.md](01_企画/組織定義.md) |
| 02 | 設計 | 要件を実現する方式・構成を決める | 設計メモ、ファイル配置案 | [組織定義.md](02_設計/組織定義.md) |
| 03 | 実装 | 設計に従ってファイルを作成・変更する | 変更差分、コミット | [組織定義.md](03_実装/組織定義.md) |
| 04 | 検証 | 受け入れ基準を満たすか確認する | 合否と根拠、指摘リスト | [組織定義.md](04_検証/組織定義.md) |

> この一覧は暫定構成。プロジェクトの実態に合わせて、名称・粒度は差し替えてよい。

## 参照ルール

依頼を受けたら、上記の**全組織**の `組織定義.md` を参照してから分担を決める。
一部の組織だけで完結させない。関係しないと判断した組織は、その理由を明示する。

## ディレクトリ構成

```
組織/
├── README.md              ← 一覧と運用手順（このファイル）
├── _テンプレート/
│   └── 組織定義.md         ← 新規組織を追加するときの雛形
├── 01_企画/組織定義.md
├── 02_設計/組織定義.md
├── 03_実装/組織定義.md

├── 05_運用/組織定義.md

```

## 組織を追加する手順

1. `組織/NN_名称/` ディレクトリを作る（`NN` は2桁の連番。実行フロー上の順序に合わせる）
2. [`_テンプレート/組織定義.md`](_テンプレート/組織定義.md) をコピーして `組織定義.md` を作る
3. 雛形の全項目を埋める（空欄を残さない。該当なしの場合は「該当なし」と書く）
4. 本ファイルの「一覧」表に行を追加する
5. 既存組織の「他組織との連携」に、新しい組織との入出力関係を反映する

## 命名規則

- ディレクトリ名: `NN_組織名`（連番2桁 + アンダースコア + 日本語の組織名）
- 定義ファイル名: `組織定義.md`（全組織で統一。参照側が固定パスで辿れるようにするため）
- 組織名は役割が分かる語にする（例: 企画、設計、検証）。人名・チーム略称は使わない。
